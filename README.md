# Shree Ranchhodraiji Mandir - Dynamic Website & Master Admin Portal

A full-fledged dynamic web portal for Shree Ranchhodraiji Mandir featuring real-time management of Aarti timings, Purnima calendars, upcoming events/notes, location map, and photo gallery uploads.

## Features Included
1. **Dynamic Aarti Timings Section:** Real-time updates for daily Aarti schedules.
2. **Purnima Dates Calendar:** Add/remove upcoming Purnima dates and special puja notes.
3. **Upcoming Events & Temple Notes:** Manage notifications, Maintenance announcements, and festival events.
4. **Photo Gallery:** Master Admin upload feature with local file storage.
5. **Location & Contact:** Google Maps integration for temple directions.
6. **Master Admin Portal:** Full password-protected dashboard to edit all content live.

## How to Deploy / Run Directly
1. Extract `ranchhodji-mandir-project.zip`.
2. Open terminal in project folder.
3. Run `npm install`
4. Run `npm start`
5. Visit `http://localhost:3000` (Public Site) or `http://localhost:3000/admin.html` (Admin Portal).

## Uploading to GitHub directly from Phone
1. Go to your GitHub account on browser or GitHub mobile app.
2. Create a new repository named `ranchhodji-mandir`.
3. Upload files directly or push using Git tools.
